# Zhalet Tapia Portfolio

A simple one-page static portfolio built with HTML and CSS.

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `portfolio`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will give you a public portfolio URL.

## Main files
- `index.html` — page content
- `styles.css` — layout and visual styling
- `assets/` — resume and Kobo project materials

Before publishing, you can replace or add projects later without changing the overall structure.
